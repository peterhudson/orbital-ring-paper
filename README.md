# Twenty Seven x Hudson: Active Support to Orbit

We are building toward a non-rocket mass-to-orbit system.

Working candidates:
- Launch loop
- Orbital ring
- Atlas tower
- Other active support structures

Core belief:
Reusable rockets are impressive, but they are still fundamentally inefficient heat engines for moving bulk mass into orbit. The long-term answer is electrically powered infrastructure.

This workspace is the operating base for that effort.

## Program goal
Design a path to the first practical electric "railroad to space": an active support structure that can move meaningful mass to orbit with high cadence, low marginal energy cost, and industrial scalability.

## First principle
Do not start by picking a favorite megastructure.
Start by defining the physics, economics, materials, control, construction, and deployment constraints that determine which concepts are actually viable.

## Immediate priorities
1. Establish the first rung: a compelling active-support demonstrator
2. Turn the coaxial levitated-rotor concept into a real engineering program
3. Identify the hardest blockers in dynamics, control, force transfer, and failure handling
4. Build a staged path from active-support demonstrators to orbital infrastructure
5. Turn this into a serious technical program, not just a sci-fi sketch
